VOID Workshop は Claude Agent SDK をベースにした、無料でオープンソースの Linux デスクトップ向けコーディングエージェントです。何かに手を付ける前に計画を立て、書き込みの前には diff を見せ、コマンドの前には必ず確認し、設定した予算で止まります。Claude のプラン、API キー、ローカルの Ollama モデルのどれでも使え、VOID Portal でスマホから操作できます。

動くのはエージェント、決めるのは人間

やりたいことを普段の言葉で伝えるだけ。手を動かすのはエージェントで、すべての変更の決定権はあなたにあります。

プロジェクトを選ぶエージェントが見られるのはそのフォルダと、明示的に追加したディレクトリだけです。
タスクを伝える普段の言葉で大丈夫。続きのメッセージは同じセッションで続きます。
計画を確認するまずは読み取り専用で調査。承認するまで何も編集されません。
操作ごとに承認する書き込みには diff を、コマンドにはコマンド・フォルダ・理由を表示します。
確認して残すファイルごとに採用・却下し、テストを実行し、好きなときにコミット。

何が変わるのかを正確に

すべての編集は書き込み前に unified diff として届きます。考えている間にディスク上のファイルが変わった場合、その編集は拒否されるので、あなた自身の作業が黙って上書きされることはありません。

  • 提案 → 適用 → テスト済み → コミット済み：ファイルごとに状態がはっきり分かります。
  • ファイル単位の採用 / 却下。却下すると元の内容に戻ります。
  • ローカルの Git チェックポイント。ブランチやインデックスには一切触れません。
  • コミットは Commit をクリックしたときだけ。push は決してしません。

モデルを信用しない前提で設計

モデルの出力もリポジトリの内容も、信頼できない入力として扱います。承認は最初の防御層であって、唯一の防御ではありません。

⌘

操作ごとの承認

正確なコマンド、作業ディレクトリ、エージェントの理由、そしてコマンドの内容（読み取り、書き込み、ネットワーク、git、インストール）。承認が記憶されることはありません。

⛨

Bubblewrap サンドボックス

エージェントのコマンドはプロジェクト内にしか書き込めず、特定のドメインを許可しない限りネットワークにも出られません。

✕

ハードブロック

sudo、広範囲の rm -rf、push、履歴の書き換え、公開、アップロード、SSH、キーリングへのアクセス、アプリ自身の設定に触れようとする操作は問答無用で拒否されます。

⌖

パスの正規化

..、シンボリックリンク、~ を使ってもプロジェクトの外には出られません。SSH キー、クラウドの認証情報、ブラウザのプロファイル、キーリングは常にアクセス禁止です。

⚿

秘密は秘密のまま

.env、秘密鍵、認証情報ファイルには明示的な承認が必要です。ログ、履歴、UI では伏せ字になります。

⏻

root では動かさない、テレメトリなし

root での実行は拒否します。作者のサーバーもプロキシもアナリティクスもありません。通信先は、あなたが選んだモデルプロバイダと、VOID Portal 用に自分でデプロイしたリレーだけです。

プランでもキーでも。正直な数字で。

Claude のプランか、デスクトップのキーリングに保存した Anthropic Console の API キーを使い、ワンクリックで切り替えられます。VOID Workshop はリクエストを 1 つ送る前に認証情報の出どころを確認します。

  • タスクごと・1 日ごとの上限（既定値：1 ドルと 3 ドル）に加え、ターン数と出力トークンの上限。
  • クレジットが尽きたら停止。クレジットの購入や課金方法の切り替えは決してしません。
  • モデルは Models API から取得（あなたのキーに応じて）。ハードコードは一切なし。
  • Console のワークスペース利用上限と組み合わせれば、確実な上限になります。
残高ではなく見積もりです。費用は Agent SDK が報告するトークン使用量から見積もっています。リトライ、キャッシュ、価格改定、組織内の他の利用によって実際の請求は変わり、アプリが残りクレジットを読み取れる API はありません。VOID Workshop はそのことをステータスバーに明記し、Console Billing へのリンクを用意しています。

本格的なエディタを、あなたの色で

プロジェクトのどのファイルも内蔵の CodeMirror エディタで開き、ちょっとした修正は自分で、残りはエージェントに任せられます。シンタックスハイライトはテーマから生成されるので、自作のものも含め、どのテーマにも合う色になります。

  • タブ、検索、保存。エージェントや他のプログラムがディスク上のファイルを変更したときは警告します。
  • マルチカーソル。元に戻す履歴はプロジェクトを切り替えても保持されます。
  • 機密ファイルは確認してから開いたり保存したりします。

VOID Portal：スマホがリモコンに

Android 用のコンパニオンアプリ。どこからでもタスクを開始・予約し、変更やコマンドを承認（通知から直接でも OK）、モデル・モード・アカウントを切り替え、タスクの完了や対応が必要なとき、PC がオフラインになったときに知らせを受け取れます。

スマホ ──wss──► 自分のリレー ◄──wss── PC
└──── エンドツーエンド暗号化、AES-256-GCM ────┘

  • QR コードでペアリング。秘密はコードの中にしかなく、リレーはそれも、プロンプトも、コードも見ることはありません。
  • 自宅側は何も公開しない。両端とも外向きに接続するので、ポート開放もポートフォワーディングも不要です。
  • デスクトップと同じルール。ブロックされたコマンドはブロックされたまま、危険なものは引き続きあなたの承認が必要です。
  • PC と揃うテーマ、Material You、色の変わるアプリアイコン。

自分のリレーを 5 分で

共有リレーはありません。各自が無料の Cloudflare アカウントに自分のリレーをデプロイするので、通信が他人のサーバーを通ることはありません。無料の Workers プランで 1 人分には十分です。

Cloudflare アカウント無料で登録して workers.dev のサブドメインを選びます。
Worker をデプロイwrangler deploy を remote/relay で実行。
確認するスモークテストがリレーに対して 18 項目をチェックします。
Workshop に設定するSettings → VOID Portal (phone) → Relay。
スマホをペアリングPair a phone をクリックし、アプリで QR コードを読み取ります。
# リポジトリのクローンから
$ cd remote/relay
$ npm install
$ npx wrangler login     # ブラウザで wrangler を承認（初回のみ）
$ npx wrangler deploy    # → https://void-relay.<your-subdomain>.workers.dev
$ node test/smoke.mjs wss://void-relay.<your-subdomain>.workers.dev

# 任意：VOID Portal のアプリ内アップデート（不要なら wrangler.toml の [[r2_buckets]] ブロックを削除）
$ npx wrangler r2 bucket create void-portal-updates

次に wss://void-relay.<your-subdomain>.workers.dev を Settings → VOID Portal (phone) → Relay に入力します。ペアリングコードやスマホをなくしたら、同じ場所でそのデバイスのペアリングを解除すれば、そのキーは使えなくなります。詳しいガイドは remote/README.md（英語）にあります。

Linux にインストール

ソースから数分でビルドし、自分のユーザーにだけインストールします。root もシステムファイルも不要です。

# 1. 依存関係（Node.js ≥ 22.13、Rust ≥ 1.80）
#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+（Node.js 22 と Rust は nodejs.org / rustup.rs から）
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

# 2. ビルドして ~/.local にインストール
$ git clone https://github.com/M4S4T0-V01D/void-workshop.git
$ cd void-workshop
$ ./scripts/build.sh
$ ./scripts/install.sh

# 3. 起動して Settings → Sign-in & API key へ：Claude でサインイン、キーを貼り付け、または Ollama を選択
$ void-workshop

よくある質問

短い答えです。詳しくはリポジトリのガイドをどうぞ。

無料ですか？

VOID Workshop と VOID Portal は無料のオープンソース（MIT）です。お金がかかるのは使うモデルの分だけ：Claude のプラン、自分の Console アカウントでの Anthropic API 利用、ローカルの Ollama モデルなら無料です。リレーは Cloudflare の無料プランに収まります。

コードやキーがどこかに送られますか？

送られるのは選んだモデルプロバイダだけです。テレメトリも作者のサーバーもありません。キーはデスクトップのキーリングに保存され、VOID Portal の通信は自分でデプロイしたリレーを通してエンドツーエンドで暗号化されます。

Claude Code とは何が違いますか？

同じ Claude Agent SDK を、レビューを中心に作られたデスクトップウィンドウで動かします。書き込み前の diff、コマンドごとの承認、ファイル単位の採用と却下、サンドボックス、利用額の上限、そしてスマホのリモコン。

どのシステムで動きますか？

Linux です（Arch で開発、WebKitGTK 4.1 のある Debian/Ubuntu などでも動作）。VOID Portal には Android 8 以降が必要です。

他の人のリレーを使えますか？

やめておきましょう。自分のものをデプロイしてください。数分で済み、無料で、通信も可用性も自分の手の中に置いておけます。
