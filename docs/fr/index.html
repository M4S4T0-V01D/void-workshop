VOID Workshop est un agent de programmation de bureau gratuit et open source pour Linux, basé sur le Claude Agent SDK. Il planifie avant de toucher à quoi que ce soit, montre un diff avant chaque écriture, demande avant chaque commande et s'arrête au budget que vous fixez. Utilisez votre abonnement Claude, une clé API ou des modèles Ollama locaux, et pilotez-le depuis votre téléphone avec VOID Portal.

L'agent agit, l'humain approuve

Décrivez ce que vous voulez avec vos mots. L'agent fait le gros du travail ; vous gardez la main sur chaque modification.

Choisissez un projetL'agent ne voit que ce dossier, plus les répertoires que vous ajoutez explicitement.
Décrivez la tâcheAvec vos mots. Les messages suivants poursuivent la même session.
Relisez le planD'abord une exploration en lecture seule. Rien n'est modifié avant votre approbation.
Approuvez chaque actionUn diff pour chaque écriture ; la commande, le dossier et la raison pour chaque commande.
Inspectez et conservezAcceptez ou rejetez chaque fichier, lancez les tests, faites un commit quand vous le décidez.

Voyez exactement ce qui va changer

Chaque modification arrive sous forme de diff unifié avant d'être écrite. Si le fichier change sur le disque pendant que vous décidez, la modification est refusée : votre propre travail n'est jamais écrasé en silence.

  • Proposé → appliqué → testé → commité : des états clairs pour chaque fichier.
  • Acceptation / rejet par fichier ; un rejet restaure le contenu d'origine.
  • Points de contrôle Git locaux qui ne touchent jamais à votre branche ni à votre index.
  • Ne commite que lorsque vous cliquez sur Commit. Jamais de push.

Conçu comme si le modèle n'était pas fiable

La sortie du modèle et le contenu du dépôt sont traités comme des entrées non fiables. L'approbation est la première couche, pas la seule.

⌘

Une approbation par action

La commande exacte, le répertoire de travail, la raison donnée par l'agent et ce que fait la commande (lectures, écritures, réseau, git, installations). Les approbations ne sont jamais mémorisées.

⛨

Bac à sable Bubblewrap

Les commandes de l'agent ne peuvent écrire que dans le projet et n'accèdent pas au réseau, sauf si vous autorisez des domaines précis.

✕

Blocages stricts

sudo, les rm -rf trop larges, les push, la réécriture de l'historique, la publication, les envois, SSH, l'accès au trousseau et les tentatives de toucher à la configuration de l'application sont refusés d'office.

⌖

Canonicalisation des chemins

.., les liens symboliques et ~ ne permettent pas de sortir du projet. Clés SSH, identifiants cloud, profils de navigateur et trousseaux restent toujours inaccessibles.

⚿

Les secrets restent secrets

.env, les clés privées et les fichiers d'identifiants exigent une approbation explicite. Les journaux, l'historique et l'interface sont caviardés.

⏻

Jamais en root, aucune télémétrie

Refuse de s'exécuter en root. Aucun serveur de l'auteur, proxy ou outil d'analyse : les seules destinations sont le fournisseur de modèles que vous avez choisi et, pour VOID Portal, le relais que vous avez déployé vous-même.

Votre abonnement ou votre clé. Des chiffres honnêtes.

Utilisez votre abonnement Claude ou une clé API Anthropic Console stockée dans le trousseau de votre bureau, et basculez en un clic. VOID Workshop vérifie la source des identifiants avant d'envoyer la moindre requête.

  • Limites par tâche et par jour (par défaut : 1 $ et 3 $), plus des plafonds de tours et de tokens de sortie.
  • S'arrête quand le crédit est épuisé et n'achète jamais de crédit ni ne change de mode de facturation.
  • Les modèles viennent de la Models API pour votre clé ; aucun n'est codé en dur.
  • Associez-le à une limite de dépenses de workspace dans la Console pour un plafond strict.
Des estimations, pas un solde. Les coûts sont estimés à partir de l'utilisation de tokens rapportée par l'Agent SDK. Les nouvelles tentatives, le cache, les changements de prix et les autres usages de votre organisation influent sur la facture réelle, et aucune API ne permet à une application de lire votre crédit restant. VOID Workshop le signale dans la barre d'état et vous renvoie vers Console Billing.

Un vrai éditeur, à vos couleurs

Ouvrez n'importe quel fichier du projet dans l'éditeur CodeMirror intégré, faites vous-même une correction rapide et laissez le reste à l'agent. La coloration syntaxique est générée à partir de votre thème : chaque thème, y compris ceux que vous créez, a des couleurs assorties.

  • Onglets, recherche et enregistrement, avec un avertissement quand l'agent ou un autre programme a modifié le fichier sur le disque.
  • Curseurs multiples et historique d'annulation conservé quand vous changez de projet.
  • Les fichiers sensibles demandent d'abord avant d'être ouverts ou enregistrés.

VOID Portal : votre téléphone comme télécommande

L'application compagnon pour Android. Lancez et mettez en file des tâches de n'importe où, approuvez modifications et commandes (directement depuis la notification si vous voulez), changez de modèle, de mode et de compte, et soyez prévenu quand une tâche est terminée, a besoin de vous ou que le PC se déconnecte.

téléphone ──wss──► votre relais ◄──wss── PC
└──── chiffré de bout en bout, AES-256-GCM ────┘

  • Associez avec un QR code. Le secret n'existe que dans le code ; le relais ne le voit jamais, pas plus que vos prompts ou votre code.
  • Rien d'exposé chez vous. Les deux côtés se connectent vers l'extérieur : aucun port ouvert, aucune redirection de port.
  • Les mêmes règles que sur le bureau. Les commandes bloquées restent bloquées ; les commandes risquées exigent toujours votre approbation.
  • Des thèmes assortis à votre PC, Material You et une icône d'application recolorée.

Installer sous Linux

Se compile depuis les sources en quelques minutes et s'installe pour votre seul utilisateur. Pas de root, aucun fichier système.

# 1. dépendances (Node.js ≥ 22.13, Rust ≥ 1.80)
#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+ (plus Node.js 22 et Rust depuis nodejs.org / rustup.rs)
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

# 2. compiler et installer dans ~/.local
$ git clone https://github.com/M4S4T0-V01D/void-workshop.git
$ cd void-workshop
$ ./scripts/build.sh
$ ./scripts/install.sh

# 3. lancer, puis Settings → Sign-in & API key : connectez-vous avec Claude, collez une clé ou choisissez Ollama
$ void-workshop

Questions

Les réponses courtes. Les guides du dépôt contiennent les longues.

Est-ce gratuit ?

VOID Workshop et VOID Portal sont gratuits et open source (MIT). Vous ne payez que le modèle que vous utilisez : votre abonnement Claude, l'usage de l'API Anthropic sur votre propre compte Console, ou rien du tout avec des modèles Ollama locaux. Le relais tient dans l'offre gratuite de Cloudflare.

Mon code ou ma clé partent-ils quelque part ?

Uniquement chez le fournisseur de modèles que vous avez choisi. Aucune télémétrie, aucun serveur de l'auteur. Les clés restent dans le trousseau de votre bureau, et le trafic de VOID Portal est chiffré de bout en bout via le relais que vous déployez vous-même.

En quoi est-ce différent de Claude Code ?

Il exécute le même Claude Agent SDK dans une fenêtre de bureau pensée pour la relecture : un diff avant chaque écriture, une approbation pour chaque commande, l'acceptation et le rejet par fichier, un bac à sable, des limites de dépenses et une télécommande sur téléphone.

Sur quels systèmes fonctionne-t-il ?

Linux (développé sous Arch, fonctionne sous Debian/Ubuntu et d'autres avec WebKitGTK 4.1). VOID Portal nécessite Android 8 ou plus récent.

Puis-je utiliser le relais de quelqu'un d'autre ?

Mieux vaut pas : déployez le vôtre. Cela prend quelques minutes, c'est gratuit, et votre trafic comme votre disponibilité restent entre vos mains.

Puis-je utiliser les applications dans ma langue ?

Oui. VOID Workshop et VOID Portal parlent les 13 mêmes langues que ce site. Les deux vous le demandent au premier démarrage ; modifiez-la ensuite dans Paramètres → Apparence et langue sur le PC et Paramètres → Langue sur le téléphone. Les traductions se trouvent dans src/i18n/locales et remote/android/app/src/main/assets/i18n, et les corrections sont les bienvenues.
