VOID Workshop وكيل برمجة مجاني ومفتوح المصدر لسطح مكتب Linux مبني على Claude Agent SDK. يضع خطة قبل أن يلمس أي شيء، ويعرض الفروقات قبل كل كتابة، ويسألك قبل كل أمر، ويتوقف عند الميزانية التي تحددها. استخدم اشتراك Claude أو مفتاح API أو نماذج Ollama المحلية، وتحكّم فيه من هاتفك عبر VOID Portal.

التثبيت على Linux احصل على VOID Portal عرض الكود المصدري

الوكيل يعمل، والإنسان يقرر

صِف ما تريده بكلماتك. يتولى الوكيل العمل الشاق، ويبقى القرار في كل تغيير بيدك.

اختر مشروعًالا يرى الوكيل إلا ذلك المجلد وأي مجلدات تضيفها صراحةً.
صِف المهمةبلغة عادية. والرسائل اللاحقة تستكمل الجلسة نفسها.
راجع الخطةاستكشاف للقراءة فقط أولًا. لا يُعدَّل شيء حتى توافق.
وافق على كل إجراءفروقات لكل كتابة، والأمر والمجلد والسبب لكل أمر.
تحقّق واحتفظاقبل أو ارفض كل ملف، وشغّل الاختبارات، ونفّذ commit متى شئت.

اعرف بالضبط ما الذي سيتغير

يصل كل تعديل على شكل unified diff قبل كتابته. وإذا تغيّر الملف على القرص أثناء تفكيرك فسيُرفض التعديل، فلا يُكتب فوق عملك أبدًا دون علمك.

  • مقترح ← مطبَّق ← مُختبَر ← مُثبَّت: حالة واضحة لكل ملف.
  • قبول / رفض لكل ملف، والرفض يعيد المحتوى الأصلي.
  • نقاط حفظ Git محلية لا تلمس فرعك ولا الفهرس أبدًا.
  • لا commit إلا عند النقر على Commit. ولا push أبدًا.

مصمَّم على افتراض أن النموذج غير موثوق

تُعامَل مخرجات النموذج ومحتوى المستودع كمدخلات غير موثوقة. الموافقة هي خط الدفاع الأول، لا الوحيد.

⌘

موافقة لكل إجراء

الأمر بالضبط، ومجلد العمل، والسبب الذي ذكره الوكيل، وما يفعله الأمر (قراءة، كتابة، شبكة، git، تثبيت). لا تُحفَظ الموافقات أبدًا.

⛨

عزل Bubblewrap

لا تستطيع أوامر الوكيل الكتابة إلا داخل المشروع، ولا تصل إلى الشبكة ما لم تسمح بنطاقات محددة.

✕

حظر صارم

يُرفض فورًا كل من sudo، وrm -rf الواسع، وpush، وإعادة كتابة السجل، والنشر، والرفع، وSSH، والوصول إلى سلسلة المفاتيح، ومحاولات تعديل إعدادات التطبيق نفسه.

⌖

توحيد المسارات

لا يمكن الخروج من المشروع باستخدام .. أو الروابط الرمزية أو ~. ومفاتيح SSH وبيانات اعتماد السحابة وملفات تعريف المتصفح وسلاسل المفاتيح محظورة دائمًا.

⚿

الأسرار تبقى سرية

تحتاج ملفات .env والمفاتيح الخاصة وملفات بيانات الاعتماد إلى موافقة صريحة، وتُحجَب في السجلات والتاريخ والواجهة.

⏻

لا يعمل كـ root ولا قياس عن بعد

يرفض العمل بصلاحيات root. لا خادم للمطوّر ولا وسيط ولا تحليلات: البيانات تذهب فقط إلى مزوّد النماذج الذي تختاره، وفي حالة VOID Portal إلى خادم الترحيل الذي نشرته بنفسك.

اشتراك أو مفتاح. وأرقام صادقة.

استخدم اشتراك Claude أو مفتاح API من Anthropic Console محفوظًا في سلسلة مفاتيح سطح المكتب، وبدّل بينهما بنقرة. يتحقق VOID Workshop من مصدر بيانات الاعتماد قبل إرسال أي طلب.

  • حدود لكل مهمة ولكل يوم (الافتراضي: 1 دولار و3 دولارات)، إضافةً إلى حدود لعدد الأدوار ورموز المخرجات.
  • يتوقف عند نفاد الرصيد، ولا يشتري رصيدًا أو يغيّر طريقة الدفع أبدًا.
  • النماذج تأتي من Models API حسب مفتاحك، ولا شيء مكتوب مسبقًا في الكود.
  • اجمعه مع حد الإنفاق لمساحة العمل في Console للحصول على سقف صارم.
هذه تقديرات وليست رصيدًا. تُقدَّر التكلفة من استهلاك الرموز الذي يبلّغ عنه Agent SDK. وتؤثر إعادة المحاولة والتخزين المؤقت وتغيّر الأسعار والاستخدامات الأخرى في مؤسستك على الفاتورة الفعلية، ولا توجد واجهة API تتيح للتطبيق قراءة رصيدك المتبقي. يوضّح VOID Workshop ذلك في شريط الحالة ويضع رابطًا إلى Console Billing.

محرر حقيقي بألوانك

افتح أي ملف في المشروع في محرر CodeMirror المدمج، وأجرِ تعديلًا سريعًا بنفسك، واترك الباقي للوكيل. يُولَّد تمييز الصيغة من سمتك، فتحصل كل سمة، بما فيها التي تصنعها، على ألوان متناسقة.

  • ألسنة وبحث وحفظ، مع تنبيه عندما يغيّر الوكيل أو برنامج آخر الملف على القرص.
  • مؤشرات متعددة، وسجل تراجع يبقى عند التنقل بين المشاريع.
  • الملفات الحساسة تسألك أولًا قبل فتحها أو حفظها.

VOID Portal: هاتفك أداة تحكم عن بعد

تطبيق مرافق لـ Android. ابدأ المهام وضعها في قائمة الانتظار من أي مكان، ووافق على التغييرات والأوامر (حتى من الإشعار مباشرةً)، وبدّل النموذج والوضع والحساب، واعرف متى تنتهي مهمة أو تحتاج إليك أو يصبح الحاسوب غير متصل.

الهاتف ──wss──► خادمك ◄──wss── PC
└──── مشفّر بين الطرفين، AES-256-GCM ────┘

  • الاقتران برمز QR. السر موجود في الرمز فقط، ولا يرى خادم الترحيل السر ولا طلباتك ولا كودك.
  • لا شيء مكشوف في منزلك. يتصل الطرفان نحو الخارج، فلا منافذ مفتوحة ولا إعادة توجيه للمنافذ.
  • القواعد نفسها كما على سطح المكتب. الأوامر المحظورة تبقى محظورة، والخطرة ما زالت تحتاج موافقتك.
  • سمات تطابق حاسوبك، وMaterial You، وأيقونة تطبيق قابلة لتغيير اللون.

خادم ترحيل خاص بك في خمس دقائق

لا يوجد خادم ترحيل مشترك: كل شخص ينشر خادمه على حساب Cloudflare مجاني، فلا تمر بياناتك أبدًا عبر خادم شخص آخر. وخطة Workers المجانية أكثر من كافية لشخص واحد.

حساب Cloudflareسجّل مجانًا واختر نطاقًا فرعيًا على workers.dev.
انشر الـ Workerwrangler deploy من داخل remote/relay.
تحقّق منهيُجري اختبار سريع 18 فحصًا على خادم الترحيل.
اربطه بـ WorkshopSettings → VOID Portal (phone) → Relay.
اقرن هاتفكانقر Pair a phone ثم امسح رمز QR من التطبيق.
# من نسختك المستنسخة من المستودع
$ cd remote/relay
$ npm install
$ npx wrangler login     # خوّل wrangler في المتصفح، مرة واحدة
$ npx wrangler deploy    # → https://void-relay.<your-subdomain>.workers.dev
$ node test/smoke.mjs wss://void-relay.<your-subdomain>.workers.dev

# اختياري: تحديثات VOID Portal داخل التطبيق (أو احذف كتلة [[r2_buckets]] في wrangler.toml)
$ npx wrangler r2 bucket create void-portal-updates

ثم أدخل wss://void-relay.<your-subdomain>.workers.dev في Settings → VOID Portal (phone) → Relay. هل فقدت رمز الاقتران أو هاتفك؟ ألغِ اقتران الجهاز من المكان نفسه فيتوقف مفتاحه عن العمل. الدليل الكامل في remote/README.md (بالإنجليزية).

هل هو مجاني؟

VOID Workshop وVOID Portal مجانيان ومفتوحا المصدر (MIT). لا تدفع إلا ثمن النموذج الذي تستخدمه: اشتراك Claude، أو استخدام Anthropic API في حساب Console الخاص بك، أو لا شيء مع نماذج Ollama المحلية. وخادم الترحيل يكفيه خطة Cloudflare المجانية.

هل يُرسَل كودي أو مفتاحي إلى أي مكان؟

فقط إلى مزوّد النماذج الذي تختاره. لا قياس عن بعد ولا خادم للمطوّر. تبقى المفاتيح في سلسلة مفاتيح سطح المكتب، وتُشفَّر بيانات VOID Portal بين الطرفين عبر خادم ترحيل تنشره بنفسك.

بماذا يختلف عن Claude Code؟

يشغّل Claude Agent SDK نفسه داخل نافذة سطح مكتب مبنية حول المراجعة: فروقات قبل كل كتابة، وموافقة على كل أمر، وقبول ورفض لكل ملف، وعزل، وحدود للإنفاق، وتحكم عن بعد من الهاتف.

على أي أنظمة يعمل؟

Linux (طُوِّر على Arch، ويعمل على Debian/Ubuntu وغيرها مع WebKitGTK 4.1). ويحتاج VOID Portal إلى Android 8 أو أحدث.

هل يمكنني استخدام خادم ترحيل شخص آخر؟

لا تفعل، بل انشر خادمك. يستغرق الأمر دقائق، وهو مجاني، ويُبقي بياناتك وتوافر الخدمة بين يديك.

هل يمكنني استخدام التطبيقين بلغتي؟

نعم. يدعم VOID Workshop وVOID Portal اللغات الـ13 نفسها التي يدعمها هذا الموقع. يسأل كلاهما عند التشغيل الأول؛ ويمكنك تغييرها لاحقًا من الإعدادات ← المظهر واللغة على الحاسوب، ومن الإعدادات ← اللغة على الهاتف. الترجمات موجودة في src/i18n/locales وremote/android/app/src/main/assets/i18n، والتصحيحات مرحّب بها.
