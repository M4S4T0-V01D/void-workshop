Dein Code. Dein Schlüssel.

VOID Workshop ist ein kostenloser Open-Source-Coding-Agent für den Linux-Desktop auf Basis des Claude Agent SDK. Er plant, bevor er etwas anfasst, zeigt vor jedem Schreiben einen Diff, fragt vor jedem Befehl und stoppt beim Budget, das du festlegst. Bring dein Claude-Abo, einen API-Schlüssel oder lokale Ollama-Modelle mit und steuere alles mit VOID Portal vom Handy aus.

Beschreibe in deinen eigenen Worten, was du willst. Der Agent erledigt die Laufarbeit; über jede Änderung entscheidest du.

Sieh genau, was sich ändert

Jede Bearbeitung kommt als Unified Diff, bevor sie geschrieben wird. Ändert sich die Datei auf der Platte, während du überlegst, wird die Bearbeitung verweigert, sodass deine eigene Arbeit nie stillschweigend überschrieben wird.

  • Vorgeschlagen → angewendet → getestet → committet: klare Zustände für jede Datei.
  • Annehmen / Ablehnen pro Datei; beim Ablehnen wird der ursprüngliche Inhalt wiederhergestellt.
  • Lokale Git-Checkpoints, die deinen Branch und Index nie anfassen.
  • Committet nur, wenn du auf Commit klickst. Niemals ein Push.

Alles in einem Fenster

Planen, bauen, prüfen und ausliefern, ohne die App zu verlassen, und genau sehen, wohin deine Tokens gehen.

Gebaut, als wäre das Modell nicht vertrauenswürdig

Modellausgaben und Repository-Inhalte gelten als nicht vertrauenswürdige Eingaben. Die Freigabe ist die erste Schutzschicht, nicht die einzige.

⌘

Freigabe pro Aktion

Der genaue Befehl, das Arbeitsverzeichnis, die Begründung des Agenten und was der Befehl tut (Lesen, Schreiben, Netzwerk, git, Installationen). Freigaben werden nie gespeichert.

⛨

Bubblewrap-Sandbox

Befehle des Agenten können nur im Projekt schreiben und erreichen das Netzwerk nicht, außer du erlaubst bestimmte Domains.

✕

Harte Sperren

sudo, breite rm -rf, Pushes, Umschreiben der Historie, Veröffentlichen, Uploads, SSH, Schlüsselbund-Zugriff und Versuche, die eigene Konfiguration der App anzufassen, werden sofort abgelehnt.

⌖

Pfad-Kanonisierung

.., Symlinks und ~ können nicht aus dem Projekt ausbrechen. SSH-Schlüssel, Cloud-Zugangsdaten, Browserprofile und Schlüsselbunde sind immer tabu.

⚿

Geheimnisse bleiben geheim

.env, private Schlüssel und Zugangsdateien brauchen eine ausdrückliche Freigabe. Logs, Verlauf und Oberfläche werden geschwärzt.

⏻

Nie als root, keine Telemetrie

Verweigert den Start als root. Kein Server des Autors, kein Proxy, keine Analytics: Die einzigen Ziele sind der Modellanbieter deiner Wahl und, für VOID Portal, das Relay, das du selbst bereitgestellt hast.

Dein Abo oder dein Schlüssel. Ehrliche Zahlen.

Nutze dein Claude-Abo oder einen Anthropic-Console-API-Schlüssel aus dem Schlüsselbund deines Desktops und wechsle mit einem Klick. VOID Workshop prüft die Herkunft der Zugangsdaten, bevor auch nur eine Anfrage rausgeht.

  • Limits pro Aufgabe und pro Tag (Standard: 1 $ und 3 $), dazu Obergrenzen für Runden und Ausgabe-Tokens.
  • Stoppt, wenn das Guthaben aufgebraucht ist, und kauft nie Guthaben nach oder wechselt die Abrechnung.
  • Modelle kommen aus der Models API für deinen Schlüssel; keines ist fest einprogrammiert.
  • Kombiniere es mit einem Ausgabenlimit für den Console-Workspace für eine harte Obergrenze.
Schätzungen, kein Kontostand. Kosten werden aus der Token-Nutzung geschätzt, die das Agent SDK meldet. Wiederholungen, Caching, Preisänderungen und andere Nutzung in deiner Organisation beeinflussen die echte Rechnung, und es gibt keine API, mit der eine App dein Restguthaben lesen kann. VOID Workshop sagt das in der Statusleiste und verlinkt auf Console Billing.

Ein echter Editor, in deinen Farben

Öffne jede Projektdatei im eingebauten CodeMirror-Editor, erledige eine schnelle Korrektur selbst und überlass den Rest dem Agenten. Die Syntaxhervorhebung wird aus deinem Theme erzeugt, sodass jedes Theme, auch deine eigenen, passende Farben bekommt.

  • Tabs, Suche und Speichern, und eine Warnung, wenn der Agent oder ein anderes Programm die Datei auf der Platte geändert hat.
  • Mehrere Cursor und ein Rückgängig-Verlauf, der Projektwechsel übersteht.
  • Sensible Dateien fragen erst, bevor sie geöffnet oder gespeichert werden.

VOID Portal: dein Handy als Fernbedienung

Die Android-Begleit-App. Starte Aufgaben und reihe sie von überall ein, gib Änderungen und Befehle frei (auf Wunsch direkt aus der Benachrichtigung), wechsle Modell, Modus und Konto und erfahre, wenn eine Aufgabe fertig ist, dich braucht oder der PC offline geht.

Handy ──wss──► dein Relay ◄──wss── PC
└──── Ende-zu-Ende-verschlüsselt, AES-256-GCM ────┘

  • Kopplung per QR-Code. Das Geheimnis steckt nur im Code; das Relay sieht weder es noch deine Prompts oder deinen Code.
  • Zu Hause ist nichts offen. Beide Seiten verbinden sich nach außen, also keine offenen Ports und keine Portweiterleitung.
  • Dieselben Regeln wie am Desktop. Gesperrte Befehle bleiben gesperrt; riskante brauchen weiterhin deine Freigabe.
  • Themes passend zu deinem PC, Material You und ein umgefärbtes App-Symbol.

Unter Linux installieren

Baut in wenigen Minuten aus dem Quellcode und installiert nur für deinen Benutzer. Kein root, keine Systemdateien.

# 1. Abhängigkeiten (Node.js ≥ 22.13, Rust ≥ 1.80)
#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+ (dazu Node.js 22 und Rust von nodejs.org / rustup.rs)
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

# 2. bauen und nach ~/.local installieren
$ git clone https://github.com/M4S4T0-V01D/void-workshop.git
$ cd void-workshop
$ ./scripts/build.sh
$ ./scripts/install.sh

# 3. starten, dann Settings → Sign-in & API key: mit Claude anmelden, einen Schlüssel einfügen oder Ollama wählen
$ void-workshop

Fragen

Die kurzen Antworten. Die Anleitungen im Repository haben die langen.

Ist es kostenlos?

VOID Workshop und VOID Portal sind kostenlos und Open Source (MIT). Du zahlst nur für das Modell, das du nutzt: dein Claude-Abo, die Anthropic-API-Nutzung auf deinem eigenen Console-Konto oder gar nichts mit lokalen Ollama-Modellen. Das Relay passt in den kostenlosen Tarif von Cloudflare.

Gehen mein Code oder mein Schlüssel irgendwohin?

Nur zum Modellanbieter deiner Wahl. Es gibt keine Telemetrie und keinen Server des Autors. Schlüssel bleiben im Schlüsselbund deines Desktops, und der Datenverkehr von VOID Portal läuft Ende-zu-Ende-verschlüsselt über das Relay, das du selbst bereitstellst.

Was unterscheidet es von Claude Code?

Es führt dasselbe Claude Agent SDK in einem Desktop-Fenster aus, das aufs Prüfen ausgelegt ist: ein Diff vor jedem Schreiben, eine Freigabe für jeden Befehl, Annehmen und Ablehnen pro Datei, eine Sandbox, Ausgabenlimits und eine Handy-Fernbedienung.

Auf welchen Systemen läuft es?

Linux (entwickelt unter Arch, läuft unter Debian/Ubuntu und anderen mit WebKitGTK 4.1). VOID Portal braucht Android 8 oder neuer.

Kann ich das Relay von jemand anderem nutzen?

Lieber nicht: Stell dein eigenes bereit. Das dauert ein paar Minuten, ist kostenlos und hält deinen Datenverkehr und deine Verfügbarkeit in deiner Hand.

Kann ich die Apps in meiner Sprache nutzen?

Ja. VOID Workshop und VOID Portal sprechen dieselben 13 Sprachen wie diese Website. Beide fragen beim ersten Start; ändern kannst du sie später unter Einstellungen → Darstellung & Sprache am PC und Einstellungen → Sprache auf dem Handy. Die Übersetzungen liegen in src/i18n/locales und remote/android/app/src/main/assets/i18n, Verbesserungen sind willkommen.
