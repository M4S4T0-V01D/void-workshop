내 승인.

VOID Workshop은 Claude Agent SDK 기반의 무료 오픈소스 Linux 데스크톱 코딩 에이전트입니다. 무언가를 건드리기 전에 계획을 세우고, 모든 쓰기 전에 diff를 보여 주고, 모든 명령 전에 물어보며, 정해 둔 예산에서 멈춥니다. Claude 요금제, API 키 또는 로컬 Ollama 모델을 가져와 VOID Portal로 휴대폰에서 조작하세요.

Linux에 설치 VOID Portal 받기 소스 보기

일은 에이전트가, 승인은 사람이

원하는 것을 평소 말투로 설명하세요. 수고로운 일은 에이전트가 하고, 모든 변경의 결정권은 여러분에게 있습니다.

프로젝트 선택에이전트는 그 폴더와 명시적으로 추가한 디렉터리만 볼 수 있습니다.
작업 설명평소 말투로 충분합니다. 이어지는 메시지는 같은 세션에서 계속됩니다.
계획 검토먼저 읽기 전용으로 탐색합니다. 승인하기 전에는 아무것도 수정되지 않습니다.
작업마다 승인쓰기마다 diff, 명령마다 명령어·폴더·이유를 보여 줍니다.
확인하고 유지파일별로 수락하거나 거부하고, 테스트를 돌리고, 원할 때 커밋하세요.

무엇이 바뀌는지 정확히

모든 편집은 쓰기 전에 unified diff로 도착합니다. 고민하는 동안 디스크의 파일이 바뀌면 그 편집은 거부되므로, 여러분의 작업이 몰래 덮어써지는 일은 없습니다.

  • 제안 → 적용 → 테스트 → 커밋: 파일마다 명확한 상태.
  • 파일별 수락 / 거부, 거부하면 원래 내용으로 복원.
  • 로컬 Git 체크포인트, 브랜치나 인덱스는 절대 건드리지 않음.
  • Commit을 클릭할 때만 커밋. push는 절대 하지 않음.

모델을 믿지 않는다는 전제로 설계

모델 출력과 저장소 내용은 신뢰할 수 없는 입력으로 취급합니다. 승인은 첫 번째 방어층일 뿐, 유일한 방어층이 아닙니다.

⌘

작업별 승인

정확한 명령, 작업 디렉터리, 에이전트가 밝힌 이유, 명령이 하는 일(읽기, 쓰기, 네트워크, git, 설치). 승인은 절대 기억되지 않습니다.

⛨

Bubblewrap 샌드박스

에이전트의 명령은 프로젝트 안에서만 쓸 수 있고, 특정 도메인을 허용하지 않는 한 네트워크에 접근할 수 없습니다.

✕

강제 차단

sudo, 광범위한 rm -rf, push, 히스토리 재작성, 배포, 업로드, SSH, 키링 접근, 앱 자체 설정을 건드리려는 시도는 곧바로 거부됩니다.

⌖

경로 정규화

.., 심볼릭 링크, ~로도 프로젝트 밖으로 나갈 수 없습니다. SSH 키, 클라우드 자격 증명, 브라우저 프로필, 키링은 언제나 접근 금지입니다.

⚿

비밀은 비밀로

.env, 개인 키, 자격 증명 파일은 명시적 승인이 필요합니다. 로그, 기록, UI에서는 가려집니다.

⏻

root 금지, 텔레메트리 없음

root로 실행하는 것을 거부합니다. 제작자 서버, 프록시, 분석 도구가 없습니다. 데이터가 가는 곳은 직접 고른 모델 제공자와, VOID Portal의 경우 직접 배포한 릴레이뿐입니다.

요금제든 키든. 정직한 숫자.

Claude 요금제나 데스크톱 키링에 저장한 Anthropic Console API 키를 쓰고, 클릭 한 번으로 전환하세요. VOID Workshop은 요청을 하나라도 보내기 전에 자격 증명의 출처를 확인합니다.

  • 작업별·일별 한도(기본값: 1달러와 3달러)와 턴 수·출력 토큰 상한.
  • 크레딧이 바닥나면 멈춤, 크레딧을 구매하거나 결제 방식을 바꾸지 않음.
  • 모델 목록은 Models API에서 키에 맞게 가져옴, 하드코딩 없음.
  • Console 워크스페이스 지출 한도와 함께 쓰면 확실한 상한이 됩니다.
잔액이 아니라 추정치입니다. 비용은 Agent SDK가 보고하는 토큰 사용량으로 추정합니다. 재시도, 캐싱, 가격 변경, 조직 내 다른 사용량이 실제 청구액에 영향을 주며, 앱이 남은 크레딧을 읽을 수 있는 API는 없습니다. VOID Workshop은 이를 상태 표시줄에 밝히고 Console Billing 링크를 제공합니다.

제대로 된 편집기를 내 색으로

프로젝트의 어떤 파일이든 내장 CodeMirror 편집기로 열어 간단한 수정은 직접 하고, 나머지는 에이전트에게 맡기세요. 구문 강조는 테마에서 생성되므로 직접 만든 테마를 포함해 모든 테마에 어울리는 색이 입혀집니다.

  • 탭, 검색, 저장, 그리고 에이전트나 다른 프로그램이 디스크의 파일을 바꿨을 때 경고.
  • 다중 커서, 프로젝트를 전환해도 유지되는 실행 취소 기록.
  • 민감한 파일은 먼저 확인한 뒤 열거나 저장.

VOID Portal: 휴대폰을 리모컨으로

Android 동반 앱입니다. 어디서든 작업을 시작하고 대기열에 넣고, 변경 사항과 명령을 승인하고(원하면 알림에서 바로), 모델·모드·계정을 전환하고, 작업이 끝났을 때나 여러분이 필요할 때, PC가 오프라인이 되었을 때 알림을 받으세요.

휴대폰 ──wss──► 내 릴레이 ◄──wss── PC
└──── 종단 간 암호화, AES-256-GCM ────┘

  • QR 코드로 페어링. 비밀은 코드 안에만 있고, 릴레이는 그것도, 프롬프트도, 코드도 보지 못합니다.
  • 집에서는 아무것도 노출되지 않음. 양쪽 모두 바깥으로 연결하므로 열린 포트도 포트 포워딩도 없습니다.
  • 데스크톱과 같은 규칙. 차단된 명령은 계속 차단되고, 위험한 명령은 여전히 승인이 필요합니다.
  • PC와 어울리는 테마, Material You, 색이 바뀌는 앱 아이콘.

5분 만에 나만의 릴레이

공용 릴레이는 없습니다. 각자 무료 Cloudflare 계정에 자신의 릴레이를 배포하므로, 내 트래픽이 다른 사람의 서버를 지나가는 일은 없습니다. 무료 Workers 요금제면 한 사람에게 충분합니다.

Cloudflare 계정무료로 가입하고 workers.dev 하위 도메인을 고르세요.
Worker 배포wrangler deploy를 remote/relay에서 실행.
확인스모크 테스트가 릴레이를 대상으로 18가지를 점검합니다.
Workshop에 연결Settings → VOID Portal (phone) → Relay.
휴대폰 페어링Pair a phone을 클릭한 뒤 앱에서 QR 코드를 스캔하세요.
# 저장소를 클론한 곳에서
$ cd remote/relay
$ npm install
$ npx wrangler login     # 브라우저에서 wrangler 인증, 한 번만
$ npx wrangler deploy    # → https://void-relay.<your-subdomain>.workers.dev
$ node test/smoke.mjs wss://void-relay.<your-subdomain>.workers.dev

# 선택: VOID Portal 앱 내 업데이트 (또는 wrangler.toml의 [[r2_buckets]] 블록 삭제)
$ npx wrangler r2 bucket create void-portal-updates

그다음 wss://void-relay.<your-subdomain>.workers.dev를 Settings → VOID Portal (phone) → Relay에 입력하세요. 페어링 코드나 휴대폰을 잃어버렸나요? 같은 곳에서 기기 페어링을 해제하면 그 키는 더 이상 작동하지 않습니다. 전체 가이드는 remote/README.md(영어)에 있습니다.

나만의 스타일로

7가지 내장 테마, 대비 경고가 있는 실시간 색상 편집기, 테마를 공유할 수 있는 JSON 가져오기/내보내기.

테마를 클릭하면 이 페이지에서 바로 적용해 볼 수 있습니다.

#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+ (Node.js 22와 Rust는 nodejs.org / rustup.rs에서)
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

$ ./scripts/install.sh

짧은 답변입니다. 자세한 내용은 저장소의 가이드에 있습니다.

무료인가요?

VOID Workshop과 VOID Portal은 무료 오픈소스(MIT)입니다. 사용하는 모델 비용만 내면 됩니다: Claude 요금제, 내 Console 계정의 Anthropic API 사용량, 또는 로컬 Ollama 모델이라면 무료. 릴레이는 Cloudflare 무료 요금제로 충분합니다.

내 코드나 키가 어딘가로 전송되나요?

직접 고른 모델 제공자에게만 갑니다. 텔레메트리도, 제작자 서버도 없습니다. 키는 데스크톱 키링에 머물고, VOID Portal 트래픽은 직접 배포한 릴레이를 통해 종단 간 암호화됩니다.

Claude Code와 무엇이 다른가요?

같은 Claude Agent SDK를 검토 중심으로 만든 데스크톱 창에서 실행합니다: 모든 쓰기 전 diff, 모든 명령의 승인, 파일별 수락과 거부, 샌드박스, 지출 한도, 그리고 휴대폰 리모컨.

어떤 시스템에서 실행되나요?

Linux(Arch에서 개발, WebKitGTK 4.1이 있는 Debian/Ubuntu 등에서도 작동). VOID Portal은 Android 8 이상이 필요합니다.

다른 사람의 릴레이를 써도 되나요?

그러지 마세요. 직접 배포하세요. 몇 분이면 되고, 무료이며, 트래픽과 가용성을 내 손에 둘 수 있습니다.
