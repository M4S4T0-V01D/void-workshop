VOID Workshop — бесплатный агент для программирования с открытым исходным кодом для рабочего стола Linux на базе Claude Agent SDK. Он составляет план, прежде чем что-либо трогать, показывает diff перед каждой записью, спрашивает перед каждой командой и останавливается на заданном вами бюджете. Подключите подписку Claude, API-ключ или локальные модели Ollama и управляйте им с телефона через VOID Portal.

Работает агент, решает человек

Опишите задачу своими словами. Агент берёт на себя рутину, а каждое изменение остаётся под вашим контролем.

Выберите проектАгент видит только эту папку и каталоги, которые вы явно добавите.
Опишите задачуСвоими словами. Следующие сообщения продолжают тот же сеанс.
Проверьте планСначала исследование только на чтение. Ничего не меняется, пока вы не одобрите.
Подтвердите каждое действиеDiff для каждой записи; команда, папка и причина для каждой команды.
Проверьте и сохранитеПринимайте или отклоняйте каждый файл, запускайте тесты, делайте коммит, когда решите.

Видно точно, что изменится

Каждая правка приходит в виде unified diff до записи. Если файл на диске изменится, пока вы решаете, правка будет отклонена, так что ваша собственная работа никогда не перезапишется незаметно.

  • Предложено → применено → протестировано → закоммичено: понятное состояние каждого файла.
  • Принять / отклонить по файлам; при отклонении исходное содержимое восстанавливается.
  • Локальные точки сохранения Git, которые не трогают вашу ветку и индекс.
  • Коммит только по нажатию Commit. Никаких push.

Спроектировано так, будто модели нельзя доверять

Вывод модели и содержимое репозитория считаются недоверенными входными данными. Подтверждение — первый уровень защиты, но не единственный.

⌘

Подтверждение каждого действия

Точная команда, рабочий каталог, причина от агента и что делает команда (чтение, запись, сеть, git, установка). Подтверждения никогда не запоминаются.

⛨

Песочница Bubblewrap

Команды агента могут писать только внутри проекта и не имеют доступа к сети, если вы не разрешите конкретные домены.

✕

Жёсткие запреты

sudo, широкие rm -rf, push, переписывание истории, публикации, выгрузки, SSH, доступ к связке ключей и попытки изменить настройки самого приложения отклоняются сразу.

⌖

Канонизация путей

.., символические ссылки и ~ не позволяют выйти за пределы проекта. SSH-ключи, облачные учётные данные, профили браузера и связки ключей всегда недоступны.

⚿

Секреты остаются секретами

.env, закрытые ключи и файлы с учётными данными требуют явного подтверждения. В журналах, истории и интерфейсе они скрываются.

⏻

Никогда от root, без телеметрии

Отказывается запускаться от root. Нет сервера автора, прокси или аналитики: данные уходят только выбранному вами поставщику моделей и, для VOID Portal, на ретранслятор, который вы развернули сами.

Подписка или ключ. Честные цифры.

Используйте подписку Claude или API-ключ Anthropic Console из связки ключей вашего рабочего стола и переключайтесь одним щелчком. VOID Workshop проверяет источник учётных данных до отправки первого запроса.

  • Лимиты на задачу и на день (по умолчанию: $1 и $3), а также ограничения на число ходов и выходных токенов.
  • Останавливается, когда кредиты заканчиваются, и никогда не покупает кредиты и не меняет способ оплаты.
  • Список моделей берётся из Models API для вашего ключа; ничего не зашито в код.
  • Сочетайте с лимитом расходов рабочей области в Console для жёсткого потолка.
Это оценки, а не баланс. Стоимость рассчитывается по расходу токенов, о котором сообщает Agent SDK. Повторные попытки, кэширование, изменения цен и другое использование в вашей организации влияют на реальный счёт, а API, через которое приложение могло бы узнать ваш остаток, не существует. VOID Workshop пишет об этом в строке состояния и даёт ссылку на Console Billing.

Настоящий редактор в ваших цветах

Откройте любой файл проекта во встроенном редакторе CodeMirror, внесите быструю правку сами, а остальное поручите агенту. Подсветка синтаксиса генерируется из вашей темы, поэтому у каждой темы, включая созданные вами, подходящие цвета.

  • Вкладки, поиск и сохранение, а также предупреждение, если агент или другая программа изменили файл на диске.
  • Несколько курсоров и история отмены, сохраняющаяся при переключении проектов.
  • Конфиденциальные файлы сначала спрашивают, прежде чем открыться или сохраниться.

VOID Portal: телефон как пульт

Приложение-компаньон для Android. Запускайте задачи и ставьте их в очередь откуда угодно, подтверждайте изменения и команды (хоть прямо из уведомления), переключайте модель, режим и аккаунт и узнавайте, когда задача готова, ждёт вас или ПК ушёл в офлайн.

телефон ──wss──► ваш ретранслятор ◄──wss── ПК
└──── сквозное шифрование, AES-256-GCM ────┘

  • Сопряжение по QR-коду. Секрет есть только в коде; ретранслятор не видит ни его, ни ваших запросов, ни вашего кода.
  • Дома ничего не открыто наружу. Обе стороны подключаются сами, поэтому не нужны ни открытые порты, ни проброс портов.
  • Те же правила, что и на ПК. Заблокированные команды остаются заблокированными; рискованные по-прежнему требуют вашего подтверждения.
  • Темы как на вашем ПК, Material You и перекрашиваемый значок приложения.

Свой ретранслятор за пять минут

Общего ретранслятора нет: каждый разворачивает свой на бесплатном аккаунте Cloudflare, поэтому ваш трафик никогда не идёт через чужой сервер. Бесплатного тарифа Workers одному человеку хватает с запасом.

Установка на Linux

Собирается из исходников за несколько минут и устанавливается только для вашего пользователя. Без root и без системных файлов.

# 1. зависимости (Node.js ≥ 22.13, Rust ≥ 1.80)
#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+ (плюс Node.js 22 и Rust с nodejs.org / rustup.rs)
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

# 2. сборка и установка в ~/.local
$ git clone https://github.com/M4S4T0-V01D/void-workshop.git
$ cd void-workshop
$ ./scripts/build.sh
$ ./scripts/install.sh

# 3. запустите, затем Settings → Sign-in & API key: войдите через Claude, вставьте ключ или выберите Ollama
$ void-workshop

Вопросы

Короткие ответы. Подробные — в руководствах в репозитории.

Это бесплатно?

VOID Workshop и VOID Portal бесплатны и имеют открытый исходный код (MIT). Вы платите только за используемую модель: подписку Claude, использование Anthropic API в своём аккаунте Console или ничего при локальных моделях Ollama. Ретранслятор укладывается в бесплатный тариф Cloudflare.

Мой код или ключ куда-то отправляются?

Только выбранному вами поставщику моделей. Нет ни телеметрии, ни сервера автора. Ключи хранятся в связке ключей вашего рабочего стола, а трафик VOID Portal шифруется сквозным шифрованием и идёт через ретранслятор, который вы развернули сами.

Чем это отличается от Claude Code?

Тот же Claude Agent SDK работает в окне рабочего стола, построенном вокруг проверки: diff перед каждой записью, подтверждение каждой команды, приём и отклонение по файлам, песочница, лимиты расходов и пульт на телефоне.

На каких системах работает?

Linux (разрабатывается на Arch, работает на Debian/Ubuntu и других с WebKitGTK 4.1). Для VOID Portal нужен Android 8 или новее.

Можно пользоваться чужим ретранслятором?

Не стоит: разверните свой. Это занимает несколько минут, бесплатно, и ваш трафик и доступность остаются в ваших руках.
