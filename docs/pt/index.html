VOID Workshop é um agente de programação para desktop Linux, gratuito e de código aberto, construído sobre o Claude Agent SDK. Ele planeja antes de mexer em qualquer coisa, mostra um diff antes de cada gravação, pergunta antes de cada comando e para no orçamento que você definir. Use seu plano Claude, uma chave de API ou modelos locais do Ollama, e controle tudo pelo celular com o VOID Portal.

O agente trabalha, você aprova

Descreva o que você quer com suas palavras. O agente faz o trabalho pesado; você continua no comando de cada alteração.

Escolha um projetoO agente só enxerga essa pasta, mais os diretórios que você adicionar explicitamente.
Descreva a tarefaCom suas palavras. As mensagens seguintes continuam a mesma sessão.
Revise o planoPrimeiro, exploração somente leitura. Nada é editado até você aprovar.
Aprove cada açãoUm diff para cada gravação; comando, pasta e motivo para cada comando.
Inspecione e mantenhaAceite ou rejeite cada arquivo, rode os testes e faça commit quando quiser.

Veja exatamente o que vai mudar

Cada edição chega como um diff unificado antes de ser gravada. Se o arquivo mudar no disco enquanto você decide, a edição é recusada, então seu próprio trabalho nunca é sobrescrito em silêncio.

  • Proposto → aplicado → testado → commitado: estados claros para cada arquivo.
  • Aceitar / rejeitar por arquivo; ao rejeitar, o conteúdo original é restaurado.
  • Checkpoints Git locais que nunca tocam no seu branch ou índice.
  • Só faz commit quando você clica em Commit. Nunca faz push.

Feito como se o modelo não fosse confiável

A saída do modelo e o conteúdo do repositório são tratados como entrada não confiável. A aprovação é a primeira camada, não a única.

⌘

Aprovação por ação

O comando exato, o diretório de trabalho, o motivo do agente e o que o comando faz (leituras, gravações, rede, git, instalações). Aprovações nunca são lembradas.

⛨

Sandbox com Bubblewrap

Os comandos do agente só podem gravar dentro do projeto e não acessam a rede, a menos que você permita domínios específicos.

✕

Bloqueios rígidos

sudo, rm -rf amplos, push, reescrita de histórico, publicações, uploads, SSH, acesso ao chaveiro e tentativas de mexer na configuração do próprio app são recusados de cara.

⌖

Canonicalização de caminhos

.., links simbólicos e ~ não conseguem sair do projeto. Chaves SSH, credenciais de nuvem, perfis de navegador e chaveiros estão sempre fora de alcance.

⚿

Segredos continuam secretos

.env, chaves privadas e arquivos de credenciais exigem aprovação explícita. Logs, histórico e interface são censurados.

⏻

Nunca como root, sem telemetria

Recusa-se a rodar como root. Sem servidor do autor, proxy ou analytics: os únicos destinos são o provedor de modelos que você escolheu e, no caso do VOID Portal, o relay que você mesmo implantou.

Seu plano ou sua chave. Números honestos.

Use seu plano Claude ou uma chave de API do Anthropic Console guardada no chaveiro do seu desktop, e troque com um clique. O VOID Workshop verifica a origem da credencial antes de enviar qualquer requisição.

  • Limites por tarefa e diários (padrão: US$ 1 e US$ 3), além de limites de turnos e de tokens de saída.
  • Para quando o crédito acaba e nunca compra créditos nem troca a cobrança.
  • Os modelos vêm da Models API para a sua chave; nenhum é fixo no código.
  • Combine com um limite de gastos do workspace no Console para um teto rígido.
Estimativas, não um saldo. Os custos são estimados a partir do uso de tokens informado pelo Agent SDK. Novas tentativas, cache, mudanças de preço e outros usos na sua organização afetam a conta real, e não existe API para um app ler seu crédito restante. O VOID Workshop avisa isso na barra de status e leva você ao Console Billing.

Um editor de verdade, com as suas cores

Abra qualquer arquivo do projeto no editor CodeMirror integrado, faça você mesmo uma correção rápida e deixe o resto para o agente. O realce de sintaxe é gerado a partir do seu tema, então cada tema, inclusive os que você criar, ganha cores combinando.

  • Abas, busca e salvamento, e um aviso quando o agente ou outro programa alterou o arquivo no disco.
  • Vários cursores e histórico de desfazer mantido ao trocar de projeto.
  • Arquivos sensíveis perguntam antes de abrir ou salvar.

VOID Portal: seu celular como controle remoto

O app complementar para Android. Inicie e enfileire tarefas de qualquer lugar, aprove alterações e comandos (direto da notificação, se quiser), troque modelo, modo e conta, e saiba quando uma tarefa termina, precisa de você ou o PC fica offline.

celular ──wss──► seu relay ◄──wss── PC
└──── criptografia de ponta a ponta, AES-256-GCM ────┘

  • Pareie com um QR code. O segredo existe só no código; o relay nunca o vê, nem seus prompts ou seu código.
  • Nada exposto em casa. As duas pontas se conectam para fora, então não há portas abertas nem redirecionamento de portas.
  • As mesmas regras do desktop. Comandos bloqueados continuam bloqueados; os arriscados ainda precisam da sua aprovação.
  • Temas que combinam com o seu PC, Material You e um ícone do app recolorido.

Não existe relay compartilhado: cada pessoa implanta o seu numa conta gratuita da Cloudflare, então seu tráfego nunca passa pelo servidor de outra pessoa. O plano gratuito do Workers é mais que suficiente para uma pessoa.

Instalar no Linux

Compila a partir do código-fonte em poucos minutos e instala só para o seu usuário. Sem root, sem arquivos do sistema.

# 1. dependências (Node.js ≥ 22.13, Rust ≥ 1.80)
#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+ (mais Node.js 22 e Rust de nodejs.org / rustup.rs)
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

# 2. compile e instale em ~/.local
$ git clone https://github.com/M4S4T0-V01D/void-workshop.git
$ cd void-workshop
$ ./scripts/build.sh
$ ./scripts/install.sh

# 3. abra e vá em Settings → Sign-in & API key: entre com o Claude, cole uma chave ou escolha o Ollama
$ void-workshop

Perguntas

As respostas curtas. Os guias no repositório têm as longas.

É gratuito?

O VOID Workshop e o VOID Portal são gratuitos e de código aberto (MIT). Você paga só pelo modelo que usa: seu plano Claude, o uso da API da Anthropic na sua própria conta do Console, ou nada com modelos locais do Ollama. O relay cabe no plano gratuito da Cloudflare.

Meu código ou minha chave vão para algum lugar?

Só para o provedor de modelos que você escolheu. Não há telemetria nem servidor do autor. As chaves ficam no chaveiro do seu desktop, e o tráfego do VOID Portal tem criptografia de ponta a ponta pelo relay que você mesmo implanta.

Qual a diferença para o Claude Code?

Ele roda o mesmo Claude Agent SDK numa janela de desktop pensada para revisão: um diff antes de cada gravação, uma aprovação para cada comando, aceitar e rejeitar por arquivo, um sandbox, limites de gastos e um controle remoto no celular.

Em quais sistemas ele roda?

Linux (desenvolvido no Arch, funciona no Debian/Ubuntu e em outros com WebKitGTK 4.1). O VOID Portal precisa do Android 8 ou mais recente.

Posso usar o relay de outra pessoa?

Não faça isso: implante o seu. Leva poucos minutos, é grátis e mantém seu tráfego e sua disponibilidade nas suas mãos.

Posso usar os apps no meu idioma?

Sim. O VOID Workshop e o VOID Portal falam os mesmos 13 idiomas deste site. Os dois perguntam na primeira abertura; depois, mude em Configurações → Aparência e idioma no PC e em Configurações → Idioma no celular. As traduções ficam em src/i18n/locales e remote/android/app/src/main/assets/i18n, e correções são bem-vindas.
