Keputusan Anda.

VOID Workshop adalah agen coding gratis dan open source untuk desktop Linux, dibangun di atas Claude Agent SDK. Ia membuat rencana sebelum menyentuh apa pun, menunjukkan diff sebelum setiap penulisan, bertanya sebelum setiap perintah, dan berhenti pada anggaran yang Anda tetapkan. Bawa paket Claude, kunci API, atau model Ollama lokal, lalu kendalikan dari ponsel dengan VOID Portal.

Agen bekerja, manusia memutuskan

Jelaskan apa yang Anda inginkan dengan kata-kata biasa. Agen mengerjakan bagian beratnya, dan setiap perubahan tetap dalam kendali Anda.

Pilih proyekAgen hanya bisa melihat folder itu dan direktori yang Anda tambahkan secara eksplisit.
Jelaskan tugasnyaDengan bahasa sehari-hari. Pesan lanjutan meneruskan sesi yang sama.
Tinjau rencananyaEksplorasi baca-saja dulu. Tidak ada yang diubah sampai Anda menyetujuinya.
Setujui setiap tindakanDiff untuk setiap penulisan; perintah, folder, dan alasan untuk setiap perintah.
Periksa dan simpanTerima atau tolak setiap file, jalankan tes, dan commit kapan pun Anda mau.

Lihat persis apa yang berubah

Setiap suntingan datang sebagai unified diff sebelum ditulis. Jika file di disk berubah saat Anda menimbang, suntingan itu ditolak, sehingga pekerjaan Anda sendiri tidak pernah tertimpa diam-diam.

  • Diusulkan → diterapkan → diuji → di-commit: status yang jelas untuk setiap file.
  • Terima / tolak per file; menolak mengembalikan isi aslinya.
  • Checkpoint Git lokal yang tidak pernah menyentuh branch atau index Anda.
  • Commit hanya saat Anda mengeklik Commit. Tidak pernah push.

Dirancang seolah model tidak bisa dipercaya

Keluaran model dan isi repositori diperlakukan sebagai masukan yang tidak tepercaya. Persetujuan adalah lapisan pertama, bukan satu-satunya.

⌘

Persetujuan per tindakan

Perintah persisnya, direktori kerja, alasan dari agen, dan apa yang dilakukan perintah itu (baca, tulis, jaringan, git, instal). Persetujuan tidak pernah diingat.

⛨

Sandbox Bubblewrap

Perintah agen hanya bisa menulis di dalam proyek dan tidak punya akses jaringan kecuali Anda mengizinkan domain tertentu.

✕

Blokir mutlak

sudo, rm -rf yang luas, push, penulisan ulang riwayat, publikasi, unggahan, SSH, akses keyring, dan upaya mengubah pengaturan aplikasi itu sendiri langsung ditolak.

⌖

Kanonisasi path

.., symlink, dan ~ tidak bisa keluar dari proyek. Kunci SSH, kredensial cloud, profil browser, dan keyring selalu terlarang.

⚿

Rahasia tetap rahasia

.env, kunci privat, dan file kredensial memerlukan persetujuan eksplisit dan disamarkan di log, riwayat, dan antarmuka.

⏻

Tidak pernah sebagai root, tanpa telemetri

Menolak berjalan sebagai root. Tidak ada server pembuat, proxy, atau analitik: data hanya pergi ke penyedia model yang Anda pilih dan, untuk VOID Portal, ke relay yang Anda deploy sendiri.

Paket atau kunci. Angka yang jujur.

Gunakan paket Claude atau kunci API Anthropic Console yang disimpan di keyring desktop Anda, dan beralih dengan satu klik. VOID Workshop memverifikasi sumber kredensial sebelum mengirim satu permintaan pun.

  • Batas per tugas dan per hari (bawaan: $1 dan $3), plus batas giliran dan token keluaran.
  • Berhenti saat kredit habis, dan tidak pernah membeli kredit atau mengganti cara pembayaran.
  • Model diambil dari Models API untuk kunci Anda; tidak ada yang di-hardcode.
  • Padukan dengan batas pengeluaran workspace di Console untuk plafon yang pasti.
Ini perkiraan, bukan saldo. Biaya diperkirakan dari penggunaan token yang dilaporkan Agent SDK. Percobaan ulang, caching, perubahan harga, dan penggunaan lain di organisasi Anda memengaruhi tagihan sebenarnya, dan tidak ada API yang memungkinkan aplikasi membaca sisa kredit Anda. VOID Workshop menyebutkannya di bilah status dan menautkan ke Console Billing.

Editor sungguhan, dengan warna Anda

Buka file mana pun di proyek dengan editor CodeMirror bawaan, lakukan perbaikan cepat sendiri, dan serahkan sisanya ke agen. Penyorotan sintaks dihasilkan dari tema Anda, sehingga setiap tema, termasuk buatan Anda sendiri, mendapat warna yang serasi.

  • Tab, pencarian, dan simpan, dengan peringatan saat agen atau program lain mengubah file di disk.
  • Banyak kursor dan riwayat undo yang tetap ada saat berpindah proyek.
  • File sensitif bertanya dulu sebelum dibuka atau disimpan.

VOID Portal: ponsel Anda sebagai remote

Aplikasi pendamping untuk Android. Mulai dan antrekan tugas dari mana saja, setujui perubahan dan perintah (bahkan langsung dari notifikasi), ganti model, mode, dan akun, dan ketahui saat tugas selesai, membutuhkan Anda, atau PC sedang offline.

ponsel ──wss──► relay Anda ◄──wss── PC
└──── terenkripsi end-to-end, AES-256-GCM ────┘

  • Pairing lewat kode QR. Rahasianya hanya ada di dalam kode; relay tidak pernah melihatnya, juga tidak melihat prompt atau kode Anda.
  • Tidak ada yang terekspos di rumah. Kedua sisi terhubung keluar, jadi tidak ada port terbuka atau port forwarding.
  • Aturan yang sama dengan desktop. Perintah yang diblokir tetap diblokir; yang berisiko tetap memerlukan persetujuan Anda.
  • Tema yang sama dengan PC Anda, Material You, dan ikon aplikasi yang bisa diganti warnanya.

Relay milik Anda dalam lima menit

Tidak ada relay bersama: setiap orang men-deploy relay sendiri di akun Cloudflare gratis, sehingga lalu lintas Anda tidak pernah melewati server orang lain. Paket Workers gratis lebih dari cukup untuk satu orang.

$ npm install
$ npx wrangler login     # otorisasi wrangler di browser, sekali saja

Lalu masukkan wss://void-relay.<your-subdomain>.workers.dev di Settings → VOID Portal (phone) → Relay. Kehilangan kode pairing atau ponsel? Lepaskan pairing perangkat di tempat yang sama dan kuncinya tidak akan berfungsi lagi. Panduan lengkap ada di remote/README.md (dalam bahasa Inggris).

Instal di Linux

Dibangun dari sumber dalam beberapa menit dan diinstal hanya untuk pengguna Anda. Tanpa root, tanpa file sistem.

# 1. dependensi (Node.js ≥ 22.13, Rust ≥ 1.80)
#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+ (plus Node.js 22 dan Rust dari nodejs.org / rustup.rs)
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

# 2. build dan instal ke ~/.local
$ git clone https://github.com/M4S4T0-V01D/void-workshop.git
$ cd void-workshop
$ ./scripts/build.sh
$ ./scripts/install.sh

# 3. jalankan, lalu Settings → Sign-in & API key: masuk dengan Claude, tempel kunci, atau pilih Ollama
$ void-workshop

Pertanyaan

Jawaban singkat. Detailnya ada di panduan dalam repositori.

Apakah gratis?

VOID Workshop dan VOID Portal gratis dan open source (MIT). Anda hanya membayar model yang Anda gunakan: paket Claude, penggunaan Anthropic API di akun Console Anda sendiri, atau gratis dengan model Ollama lokal. Relay cukup dengan paket gratis Cloudflare.

Apakah kode atau kunci saya dikirim ke suatu tempat?

Hanya ke penyedia model yang Anda pilih. Tidak ada telemetri dan tidak ada server pembuat. Kunci tetap di keyring desktop Anda, dan lalu lintas VOID Portal terenkripsi end-to-end melalui relay yang Anda deploy sendiri.

Apa bedanya dengan Claude Code?

Ia menjalankan Claude Agent SDK yang sama di dalam jendela desktop yang dirancang untuk peninjauan: diff sebelum setiap penulisan, persetujuan untuk setiap perintah, terima dan tolak per file, sandbox, batas pengeluaran, dan remote di ponsel.

Berjalan di sistem apa saja?

Linux (dikembangkan di Arch, berjalan di Debian/Ubuntu dan lainnya dengan WebKitGTK 4.1). VOID Portal memerlukan Android 8 atau lebih baru.

Bisakah saya memakai relay orang lain?

Jangan: deploy milik Anda sendiri. Hanya butuh beberapa menit, gratis, dan lalu lintas serta ketersediaannya tetap di tangan Anda.
