Tu código. Tu clave.
Tu aprobación.

VOID Workshop es un agente de programación de escritorio gratuito y de código abierto para Linux, basado en el Claude Agent SDK. Planifica antes de tocar nada, muestra un diff antes de cada escritura, pregunta antes de cada comando y se detiene en el presupuesto que fijes. Trae tu plan de Claude, una clave de API o modelos locales de Ollama, y manéjalo desde tu teléfono con VOID Portal.

Ve exactamente qué va a cambiar

Cada edición llega como un diff unificado antes de escribirse. Si el archivo cambia en disco mientras decides, la edición se rechaza, así que tu propio trabajo nunca se sobrescribe sin aviso.

  • Propuesto → aplicado → probado → confirmado: estados claros para cada archivo.
  • Aceptar / rechazar por archivo; al rechazar se restaura el contenido original.
  • Puntos de control Git locales que nunca tocan tu rama ni tu índice.
  • Solo hace commit cuando pulsas Commit. Nunca hace push.

Diseñado como si el modelo no fuera de fiar

La salida del modelo y el contenido del repositorio se tratan como entradas no confiables. La aprobación es la primera capa, no la única.

⌘

Aprobación por acción

El comando exacto, el directorio de trabajo, el motivo del agente y lo que hace el comando (lecturas, escrituras, red, git, instalaciones). Las aprobaciones nunca se recuerdan.

⛨

Sandbox con Bubblewrap

Los comandos del agente solo pueden escribir dentro del proyecto y no acceden a la red salvo que permitas dominios concretos.

✕

Bloqueos estrictos

sudo, rm -rf amplios, push, reescritura del historial, publicaciones, subidas, SSH, acceso al llavero e intentos de tocar la configuración de la propia aplicación se rechazan sin más.

⌖

Canonicalización de rutas

.., los enlaces simbólicos y ~ no pueden salir del proyecto. Las claves SSH, credenciales de la nube, perfiles del navegador y llaveros están siempre vetados.

⚿

Los secretos siguen siendo secretos

.env, las claves privadas y los archivos de credenciales requieren aprobación explícita. Los registros, el historial y la interfaz se censuran.

⏻

Nunca como root, sin telemetría

Se niega a ejecutarse como root. Sin servidor del autor, proxy ni analíticas: los únicos destinos son el proveedor de modelos que elegiste y, para VOID Portal, el relay que desplegaste tú.

Tu plan o tu clave. Cifras honestas.

Usa tu plan de Claude o una clave de API de Anthropic Console guardada en el llavero de tu escritorio, y cambia con un clic. VOID Workshop comprueba el origen de la credencial antes de enviar una sola petición.

  • Límites por tarea y diarios (por defecto: 1 $ y 3 $), además de topes de turnos y de tokens de salida.
  • Se detiene al agotarse el crédito y nunca compra crédito ni cambia la facturación.
  • Los modelos vienen de la Models API para tu clave; ninguno está fijado en el código.
  • Combínalo con un límite de gasto del workspace en Console para un tope estricto.
Estimaciones, no un saldo. Los costes se estiman a partir del uso de tokens que informa el Agent SDK. Los reintentos, la caché, los cambios de precio y otros usos de tu organización afectan a la factura real, y no existe ninguna API con la que una aplicación pueda leer tu crédito restante. VOID Workshop lo indica en la barra de estado y te enlaza a Console Billing.

Un editor de verdad, con tus colores

Abre cualquier archivo del proyecto en el editor CodeMirror integrado, haz tú mismo un arreglo rápido y deja el resto al agente. El resaltado de sintaxis se genera a partir de tu tema, así que cada tema, incluidos los que crees, tiene colores a juego.

  • Pestañas, búsqueda y guardado, y un aviso cuando el agente u otro programa cambió el archivo en disco.
  • Múltiples cursores e historial de deshacer que se conserva al cambiar de proyecto.
  • Los archivos sensibles preguntan antes de abrirse o guardarse.

VOID Portal: tu teléfono como control remoto

La app complementaria para Android. Inicia y encola tareas desde cualquier lugar, aprueba cambios y comandos (incluso desde la notificación), cambia de modelo, modo y cuenta, y entérate cuando una tarea termina, te necesita o el PC se desconecta.

teléfono ──wss──► tu relay ◄──wss── PC
└──── cifrado de extremo a extremo, AES-256-GCM ────┘

  • Empareja con un código QR. El secreto solo vive en el código; el relay nunca lo ve, ni tus prompts ni tu código.
  • Nada expuesto en casa. Ambos extremos se conectan hacia fuera, así que no hay puertos abiertos ni redirección de puertos.
  • Las mismas reglas que en el escritorio. Los comandos bloqueados siguen bloqueados; los arriesgados siguen necesitando tu aprobación.
  • Temas a juego con tu PC, Material You y un icono de la app recoloreado.

Instalar en Linux

Se compila desde el código fuente en unos minutos y se instala solo para tu usuario. Sin root ni archivos del sistema.

# 1. dependencias (Node.js ≥ 22.13, Rust ≥ 1.80)
#    Arch Linux
$ sudo pacman -S --needed base-devel nodejs npm rust git webkit2gtk-4.1 gtk3 libsoup3 \
    librsvg libayatana-appindicator openssl libsecret bubblewrap socat ripgrep
#    Debian / Ubuntu 24.04+ (más Node.js 22 y Rust desde nodejs.org / rustup.rs)
$ sudo apt install build-essential git libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
    librsvg2-dev libayatana-appindicator3-dev libssl-dev libsecret-1-dev bubblewrap socat ripgrep

# 2. compila e instala en ~/.local
$ git clone https://github.com/M4S4T0-V01D/void-workshop.git
$ cd void-workshop
$ ./scripts/build.sh
$ ./scripts/install.sh

# 3. ábrelo y en Settings → Sign-in & API key: inicia sesión con Claude, pega una clave o elige Ollama
$ void-workshop

Preguntas

Las respuestas cortas. Las guías del repositorio tienen las largas.

¿Es gratis?

VOID Workshop y VOID Portal son gratuitos y de código abierto (MIT). Solo pagas por el modelo que uses: tu plan de Claude, el uso de la API de Anthropic en tu propia cuenta de Console, o nada con modelos locales de Ollama. El relay cabe en el plan gratuito de Cloudflare.

¿Mi código o mi clave van a algún sitio?

Solo al proveedor de modelos que elegiste. No hay telemetría ni servidor del autor. Las claves se quedan en el llavero de tu escritorio, y el tráfico de VOID Portal va cifrado de extremo a extremo a través del relay que despliegas tú.

¿En qué se diferencia de Claude Code?

Ejecuta el mismo Claude Agent SDK en una ventana de escritorio pensada para revisar: un diff antes de cada escritura, una aprobación para cada comando, aceptar y rechazar por archivo, un sandbox, límites de gasto y un control remoto en el teléfono.

¿En qué sistemas funciona?

Linux (desarrollado en Arch, funciona en Debian/Ubuntu y otras con WebKitGTK 4.1). VOID Portal necesita Android 8 o posterior.

¿Puedo usar el relay de otra persona?

Mejor no: despliega el tuyo. Lleva unos minutos, es gratis y deja tu tráfico y tu disponibilidad en tus manos.
